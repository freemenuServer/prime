How this version works

The screenshot shows EMA20/EMA50, momentum, bid-side pressure, candle delta, relative volume, range location and a closed-candle lock. This build uses a disclosed local rule: trend 40%, candle-flow proxy 35%, momentum 15%, range location 10%; confidence comes from the absolute combined score and is checked against the editable threshold. It does not reproduce Guardeer’s private scoring weights, DOM, footprint feed, calendar API or AWS cross-device lock.

Analysis stays WAIT until real candle CSV is loaded. This is an analytical aid, not trade execution.
